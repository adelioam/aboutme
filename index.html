Kreasi Saya

MiniCode Studio

Saya memiliki hobi coding dan membuat program sendiri, ini adalah aplikasi pertama yg saya buat dlm waktu hanya sekitar 3 jam 😋. Baca selengkapnya

Aplikasi ini dapat memungkinkan penggunanya untuk melakukan pengetikan atau coding semacam VSCode Studio tapi dengan size yang lebih ringan dan memiliki 2 mode utama, yakni Code Editor untuk aktivitas pengetikan kode kompleks seperti coding dan programming serta Text Editor untuk mengetik biasa seperti membuat catatan.

Aplikasi ini mendukung semua format file yang berbentuk teks (yap, literally semua jenis file yg mengandung teks!) seperti .txt .py dll.

Download (atau cari minicode studio di google)

Simple Dock

Punya dua HP dan yang satunya nganggur? Jadiin dock aja! Baca selengkapnya

Aplikasi ini memungkinkan HP Anda masuk ke mode Dock atau Standby. Sangat cocok digunakan jika Anda ingin memanfaatkan HP lama sebagai Smart Display (layar informasi) yang estetik di meja belajar atau meja kerja.

Di dalam aplikasi ini, kamu bisa melihat info seperti: jam, tanggal, Eye Protection Notification (EPN), indikator baterai, intensitas cahaya, dan volume. Selain itu, aplikasi ini juga dilengkapi WebView sederhana yang terintegrasi untuk memutar musik lewat YouTube Music, mengecek perkiraan cuaca, browsing di Google, dan lain-lain.

Eh, klo layar HP mu AMOLED/OLED, kami menyediakan fitur Anti Burn-In. Jadi setiap beberapa detik/menit, tampilan pixel diubah secara acak agar tiap pixel OLED tidak overheat. Tidak dipakai sementara? Tinggal tap bagian atas layar dengan kartu untuk mematikan layar.

Minhy OS

Selain itu, saya juga membuat sistem operasi sendiri yang memiliki konsep Hybrid. Baca selengkapnya

Sistem operasi berbasis Debian Linux yang saya kembangkan dengan fokus pada performa ringan, dukungan hybrid, dan kemudahan kustomisasi.

Hybrid Operating System

OS ini memiliki dukungan untuk menjalankan aplikasi dari dua platform yang berbeda secara langsung! km bisa jalanin app Windows (berformat .exe .msi dll.) serta aplikasi Linux (berformat .deb dan lainnya)

Oiya, ada beberapa settingan tambahan seperti Hybrid Power Plan, Controlled Hybrid CPU Management, Dynamic Memory Allocation, WiH (Wine Hybrid) Control Panel dan beberapa settingan lain yang tersedia di pengaturan untuk efektifitas penggunaan.
